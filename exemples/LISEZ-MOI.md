# Images d'exemple

Images **entièrement dessinées par programme** (`outils/generer_exemples.py`) : aucune photo, aucune
œuvre de tiers. Elles sont dédiées au **domaine public (CC0)** : utilisez-les librement.

Ouvrez ce dossier avec 36Frame pour essayer ses fonctions :

| Image | Pour essayer |
|---|---|
| `paysage-*.jpg` | navigation, miniatures, diaporama, Mosaïque Dossier |
| `paysage-nuit-portrait.jpg` | image en hauteur (mode adaptatif) |
| `panorama-ville-tres-grand.jpg` (8000 x 2600) | zoom à 100 % et au-delà, `1:1`, déplacement dans l'image |
| `planete-detouree.png` | fond transparent : la fenêtre laisse voir ce qu'il y a derrière |
| `orbites-animees.gif`, `orbites-animees.webp` | animations (aussi dans la Mosaïque Dossier) |
| `fractale.png`, `mosaique-hexagones.png`, `vagues.webp` | formats PNG et WebP |

Pour les recréer : `python outils/generer_exemples.py` (résultat identique à chaque fois).
